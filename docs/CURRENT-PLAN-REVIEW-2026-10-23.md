## Scope and explicit version

The owner approved a separate current profile: actual models review an
immutable plan first; a later price confirmation and independently fresh quote
then pass deterministic authorization and the existing native Risk/SIM path.
The old two-post-quote-review profile and frozen research campaigns are not
changed. This is not historical reconstruction, matched A/B, blind or LIVE
qualification.

Mode: `CURRENT_PLAN_REVIEW_THEN_FRESH_QUOTE_NATIVE_SIM_V3`.
Strategy identity: `current-plan-reviewed-catalyst.v1` /
`current-chain.plan-reviewed-sim.v3`.

Planning review, original model response, fresh entry authorization, observed
request, later native Risk admission and native SIM receipt are distinct
objects. The final review is explicitly deterministic; it does not pretend
that the model reviewed an executable intent created after its response.

## Preserved limits

- Same fixed five instruments and existing Catalyst/technical/context geometry.
- Native Text relevance/freshness, Macro, Router classification and model routes.
- Original publication/event/receive/persistence clocks and content hashes.
- Maximum two-second executable quote age, no renewal of an expired entry.
- First full post-review minute and contiguous native confirmation history.
- Current defense/regime, immutable stop/target and natural variable frequency.
- Cash-only Macro or no allocation to this strategy blocks review and entry.
- Existing independent native Risk and sealed original native SIM replay.
- One original source epoch, no reconnect/stitch/re-root, at most 900 seconds.
- Existing cumulative OpenAI $12 authority, conservative unknown holds, local
  pre-call envelope $1 / 24 attempts, no retry, no new key or project.
- No real venue orders, primary/legacy/R7 database or queue mutations.

Planning-only TTLs are separately bounded; they do not make executable quotes
fresh. If an observed request exists, the remaining original source epoch can
supply natural exits. Missing future bars remain an incomplete lifecycle, not
a forced close.

## Acceptance boundaries

Actual selected news, native Text output, official Macro context and actual
allocation must be joined to the retained physical provider requests/replies.
The exact plan review and any directional creation response must also match
their request bytes, reservation, model identity and original clocks. A model
call occurring elsewhere in the run is insufficient.

Outer bootstrap/source/cleanup failures override an inner traversal completion
marker. Native entry and full trade lifecycle are reported separately. Test
fixtures establish engineering behavior only; they cannot establish a real
news/model/Risk/SIM pass or profitability.
